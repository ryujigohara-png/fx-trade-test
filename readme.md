# FXトレード検証用 PWAアプリ 機能仕様書案

## 1. アプリケーション概要

* **アプリ名:** FX Trade Test (PWA)
* **対象ペア:** AUD/JPY（15分足等の月別バックテストデータ）
* **目的:**
* 過去25年間のヒストリカルデータとバックテスト結果を月ごとにブラウザ（PWA）上で視覚的に確認する。
* チャート上のエントリー・エグジット・勝敗を検証し、トレードルールの改善点（エントリー精度向上）を見出す。


* **動作環境:** PCおよびモバイル端末（レスポンシブ対応、PWAによるオフライン対応・ホーム画面インストール可能）

---

## 2. 画面構成とUIデザイン

* **カラーテーマ:** ダークモード基調 (`#121212` / `#000000`)、視認性の高いハイコントラスト配色。
* **コントロールパネル（ヘッダー部）：**
* **通貨ペア表示:** `AUD/JPY`
* **年月セレクター:** 2001年から現在までの「年」「月」を選択可能（ローカルストレージに前回の選択状態を保存）。
* **操作ボタン群:**
* `◀◀`（最古へジャンプ）
* `大` / `小`（チャートの拡大・縮小）
* `▶▶`（直近へジャンプ・リセット）
* `凡例`（インジケータ・売買ラインの凡例表示のON/OFF切替）




* **チャートエリア:**
* Plotly.jsを用いた高パフォーマンスなローソク足チャート。
* タッチ操作（パン・ピンチズーム）およびマウスホイールでのスクロールに対応。


* **カスタムツールチップ:**
* チャート上をホバー、またはタップした位置のローソク足に十字カーソル（スパイク）を表示。
* タップ／ホバー位置の正確なローソク足データ（日時、OHLC、算出価格）および各種インジケータ値を縦1列の高密度レイアウトでポップアップ表示。



---

## 3. チャート描画およびテクニカル指標（インジケータ）仕様

* **メインチャート（ローソク足）:**
* 上昇足・下降足の色分け表示。


* **移動平均線（SMA）:**
* `SMA 9` （短期）
* `SMA 36` （中期）
* `SMA 144` （長期）


* **ボリンジャーバンド（BB）:**
* `36BB` （±1σ, ±2σ）
* `144BB` （Mid, ±1σ, ±2σ）


* **バックテスト・トレードログ可視化:**
* **BUY / SELL マーカー:** エントリーポイントの方向を上下の矢印で表示。
* **Entry / Exit マーカー:** エントリー位置（白抜き円）、エグジット位置（四角）を表示。
* **Win / Lose ライン:** エントリーからエグジットまでの軌跡を、利益トレード（青系）と損失トレード（赤系）の色分けラインで結んで表示。



---

## 4. インタラクション・操作仕様

* **データロード:**
* 選択された年月に応じて `json/{year}_{month}.json` を非同期（fetch）で動的読み込み。データ不存在時はメッセージを表示。


* **タップ・ホバー操作:**
* Plotlyの標準イベント (`plotly_click`, `plotly_hover`) を利用し、選択されたローソク足のインデックス（`pointIndex`）を正確に取得。
* タップ位置に対応する正確なOHLC値、十字価格、各種テクニカル指標の数値をカスタムツールチップ（`#custom-tooltip`）に即時反映。


* **自動Y軸スケーリング (`autoScaleY`):**
* チャートの横軸（表示範囲）を変更・ズレさせたり、ズームイン・アウトを行ったりした際、画面内にあるローソク足やトレードラインの最高値・最安値に基づいてY軸の表示レンジを自動調整。

## 5. PWA（Progressive Web App）仕様

* **マニフェスト (`manifest.json`):** アプリ名やテーマカラーの定義。
* **サービスワーカー (`sw.js`):** オフラインキャッシュおよびPWAとしてのインストール機能をサポート。
